# Rental Car Budget Checker

This is a simple Python project that checks if a user can afford a luxury car based on their budget.  
It also collects the user's contact number for follow-up.

## How It Works
- Asks for your name and car preference
- Asks your budget
- If budget >= $10,000: you can afford a luxury car!
- If not: collects contact number for other options

## Usage
Run the script in a terminal:

```bash
python rentalcar.py
